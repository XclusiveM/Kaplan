- [ ] Ссылки в мессенджерах: `USERNAME` в MAX и Telegram (в `index.html`, в блоке «Записаться» и в подвале).
- [ ] ИНН в подвале (`ИНН: [указать]`).
- [ ] Страницы `policy.html` (политика обработки ПДн) и `offer.html` (условия оказания услуг). Файлов пока нет.
- [ ] Подтвердить у Дарьи: диплом (ООО «Онлайн Институт Смарт», 2023, 1500 часов), сертификат (2024), цены (1500 / от 2500 / от 3000 / 2000 ₽), формулировку «Владимировна» в подвале.
- [ ] Отправка формы: сейчас только сообщение об отправке. Нужна Tilda-форма, webhook или YCLIENTS (см. TODO в скрипте).
- [ ] Согласие на обработку ПДн и уведомление Роскомнадзора (особая категория данных о психологическом состоянии клиентов).
- [ ] Отзывы клиентов: в этой версии блок убран. Публиковать можно только реальные отзывы с письменного согласия авторов.
